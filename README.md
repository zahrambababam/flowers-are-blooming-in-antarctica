# Flowers Are Blooming in Antarctica

A viewing room for Zahra Najafi's "Flowers Are Blooming in Antarctica" collection, Part A.

- `index.html` — the portfolio gateway page (entry point)
- `flowers-are-blooming-in-antarctica.html` — the collection site itself
- `flowers-assets/` — images, the swipeable deck pages, and (once added) the presentation video

Static site, no build step. Deploys as-is.
